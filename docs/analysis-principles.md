# Analysis Principles

1. Rank for manual review; do not enforce.
2. Compare against matched controls, not only population averages.
3. Require repeated observations across unrelated targets and sessions.
4. Preserve and display uncertainty.
5. Distinguish captured cues from unknown external information.
6. Keep client telemetry separate from server-authoritative data.
7. Prefer explainable feature rates over opaque probability scores.
8. Retain raw events and algorithm versions for replay.
